PUBLICAR GRATIS EN GITHUB PAGES
1) Crear un repositorio nuevo en GitHub, por ejemplo: victorio-tripode-films
2) Subir TODO el contenido de esta carpeta a la raíz del repositorio.
3) En GitHub: Settings > Pages.
4) En "Build and deployment", elegir "Deploy from a branch".
5) Branch: main / root y guardar.
6) GitHub dará una URL temporal tipo usuario.github.io/victorio-tripode-films/

DOMINIO PROPIO
Cuando esté comprado victoriotripodefilms.com.ar:
1) GitHub > Settings > Pages > Custom domain.
2) Escribir: victoriotripodefilms.com.ar
3) En NIC Argentina configurar los DNS que correspondan a GitHub Pages.
4) Activar "Enforce HTTPS" cuando GitHub lo habilite.
